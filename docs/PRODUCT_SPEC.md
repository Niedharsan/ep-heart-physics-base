# Product specification

## Long-term purpose

Create an original browser-based educational cardiac electrophysiology platform with real-time tissue propagation, ECG/EGM generation, pacing, catheter interaction and physical ablation.

## Phase-one purpose

Provide a clean executable foundation that proves:

1. numerical state can evolve outside React;
2. tissue activation is generated by reaction–diffusion dynamics;
3. interventions alter the simulated tissue rather than swapping prerecorded traces;
4. derived waveforms can be streamed to a browser UI;
5. the codebase can be verified, profiled and expanded in controlled stages.

## Student-learning architecture foundation

Versioned scenarios, electrodes, measurements and lessons are declarative,
JSON-safe and framework-independent. Numerical integration, signal sampling and
render publication have separate clocks. The current catalog is intentionally
small; authoring workflows, scoring and persistence are later product work.

## Explicit non-goals for this base

- Epicardio feature parity
- patient-specific anatomy
- clinical decision support
- quantitative 12-lead ECG accuracy
- detailed human ionic currents
- electromechanical contraction
- regulatory validation
