# Visual Phase 0 Task 1 — Global minimal design refresh

## Scope

This package adds a final site-wide visual layer and reorganises the simulator controls without changing numerical or assessment logic.

## Changes

- Shared colour, spacing, radius, typography and focus tokens.
- Flatter navigation, panels, buttons, forms and warnings.
- Reduced landing-page hero scale and card chrome.
- Compact simulator header and grouped primary controls.
- Solver/display tuning moved into a native collapsible section.
- Cleaner tissue, metrics and pseudo-ECG presentation.
- Unified assessment navigation, panels, scorebars and task cards.
- Responsive refinements for desktop, tablet and mobile.
- Reduced-motion and keyboard-focus handling.

## Explicitly unchanged

- Solver, diffusion and reaction model.
- Web Worker execution.
- Stimulus parameters and scenario definitions.
- Pseudo-ECG generation.
- EGM waveform generation and marking logic.
- Assessment scores, persistence and instructor/student content.
